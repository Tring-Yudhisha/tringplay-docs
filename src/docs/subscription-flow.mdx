# Subscription & Billing

This section details the subscription and billing process. We support **InPlayer** and **Cleeng**. Subscription APIs use the **same authentication** as the chosen auth provider:

- **InPlayer subscriptions** — Use **InPlayer** sign-in  `Authorization: Bearer <access_token>`
- **Cleeng subscriptions** — Use **Cleeng** sign-in `Authorization: Bearer <jwt>` 

---

## InPlayer Subscription

**Base URL**

- **Production:** `https://services.inplayer.com`
- **Staging / Sandbox:** `https://staging-v2.inplayer.com`

For sandbox, use the Staging base URL for all endpoints below.

### Get Subscriptions

**Request URL:** `https://services.inplayer.com/subscriptions`

**Method:** `GET`

**Headers:** `Authorization: Bearer <access_token>`

**Response:**

```json
{
  "collection": [
    {
      "id": 98765,
      "item_id": 148332,
      "status": "active",
      "expires_at": 1760000000
    }
  ]
}
```

**Notes:** Returns the customer’s subscriptions. Use the same access token obtained from InPlayer sign-in.

## Cleeng Subscription

**Base URL**

- **Production:** `https://mediastore.cleeng.com`
- **Sandbox/Staging:** `https://mediastore-sandbox.cleeng.com`

**Note:** Some deployments use https://mediastoreapi.cleeng.com (and mediastoreapi-sandbox) for subscription and payment endpoints. Use the deployment’s base URL.

For sandbox, use the Sandbox base URL for all endpoints below.

### Get Subscriptions

**Request URL:** `https://mediastore.cleeng.com/customers/{customerId}/subscriptions`

**Method:** `GET`

**Headers:** 
```
Authorization: Bearer <jwt>
Content-Type: application/json
```

**Response:**

```json
{
  "responseData": {
    "items": [
      {
        "subscriptionId": 114413503,
        "offerId": "S205171942_US",

        "nextPaymentAt": 1771843881,

### Get Payment Details

**Request URL:** `https://mediastore.cleeng.com/customers/{customerId}/payment_details`

**Method:** `GET`

**Headers:** 
```
Authorization: Bearer <jwt>
